# SQL Data Warehouse Project

## Overview
An end-to-end SQL Data Warehouse project demonstrating the design and implementation of a modern data warehouse using SQL Server. The project follows the Medallion Architecture (Bronze, Silver, and Gold layers) to build an ETL pipeline and transform raw data into analytical datasets.

## Architecture
The data warehouse follows a three-layer architecture:

- Bronze: Stores raw data from source systems.
- Silver: Cleans, standardizes, and transforms data.
- Gold: Contains business-ready data organized for analytical reporting.

## Technologies Used
